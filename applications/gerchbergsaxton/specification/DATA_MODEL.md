# Data model

## Stored project inputs

The project document stores these exact application-owned fields:

| JSON path | Type and stored meaning | Default / rule |
| --- | --- | --- |
| `metadata.id` | Stable project identifier string. | Generated by FullMeta and read-only in the editor. |
| `metadata.name` | Editable project display name shown in project settings. | Example: `Letter M Hologram`. The project-tree root shows the selected application's display name. |
| `model.target.svg` | Required nonempty string containing the complete self-contained SVG source. The raster target is derived, not stored in the project. | Example is a centered capital M. |
| `model.target.targetWidthRadPerUm` | Optional positive number: physical width in rad/µm represented by the complete square SVG `viewBox`. Artwork-to-viewBox ratio determines occupied target size. | New project: `2π`. Validate dynamically within `[2π/(NΔx), 2π/Δx]`. If absent in a legacy project, set in memory to `2π/Δx`; ordinary Save persists the migrated field. |
| `model.illumination.amplitudeFunction` | Optional scalar expression `A(x,y)`, with `x` and `y` in µm at sample centers. Empty/missing means `1`. | Bundled example: `exp(-((x/89.6)^2+(y/89.6)^2))`. |
| `model.illumination.apertureRadius` | Circular aperture radius `R` in µm. | Bundled example: 50 µm; require `0<R≤NΔx/2`. |
| `model.illumination.gridSize` | Integer sample count `N` on each square-grid side; the array has `N×N` values. | 256; declarative V-rule accepts exactly 64, 128, or 256. |
| `model.illumination.samplePitchUm` | Positive number `Δx` in µm between adjacent sample centers in each direction. | 1 µm. `L=NΔx`, `Δk=2π/(NΔx)`, and Nyquist extent is `±π/Δx`. |
| `model.illumination.wavelengthNm` | Positive free-space wavelength in nm. | 532 nm. Convert to µm for `k₀=2π/λ`; require every nonzero target bin to satisfy `kx²+ky²≤k₀²`. |
| `model.study` | Array containing exactly one fixed Study object. | Fixed item: ID `gs-study`, name `Far-field hologram study`, type `farFieldPhaseOnly`. No add/remove/reorder/rename/duplicate actions. |
| `model.study[0].iterations` | Integer requested GS iteration count. | 40; allowed 1–100. |
| `model.study[0].seed` | Unsigned 32-bit integer for deterministic phase initialization. | 20261110; allowed 0–4294967295. |

`N` and `Δx` are independent inputs, not redundant controls. `N` sets array dimensions and, at fixed `Δx`, physical aperture-plane width and far-field bin spacing. `Δx` sets physical sample spacing and Nyquist wavevector range. `λ` controls only the propagating-wave disk; it does not rescale the plotted `kx,ky` axes.

The visible project-tree row for the `/model/illumination` object is **Design parameters**. This is a presentation label only; the persisted JSON key and all runtime field paths remain `model.illumination`.

Use explicit units for physical quantities. Preserve the SVG source and numeric settings through editing, saving, and reopening. The schema defines legal ranges and required values. The default computational grid is 256 by 256 samples.

## Derived data

The phase map, target amplitude, and reconstructed intensity are derived outputs, not scientific input fields in project JSON. Run Study writes them with the exact saved input snapshot to a project-local run directory and records their identity and state in its manifest. Phase samples where effective illumination is zero are undefined: store them as JSON `null` and display them transparent. Retain the two newest completed runs, show their history in Study Settings, restore the newest result on project reopen, and let **Clear Results** remove the project's retained runs through the standard confirmed cleanup workflow. Run progress and current tree selection remain transient editor state.

## Example project

The Letter M Hologram project is an ordinary project document routed to this application's schema. Its Inputs contain an SVG path drawing a capital M, an inscribed circular aperture, and a centered Gaussian illumination amplitude profile. Its single Study item contains the iteration count and initialization seed so it can be selected and run without first editing the model.
